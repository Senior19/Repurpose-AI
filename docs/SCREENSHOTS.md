# Capturing genuine project screenshots

Screenshots should come from the running application, not generated mockups.

Capture these views after starting the app and retrieving real results:

1. **Disease Explorer:** disease overview and returned target associations.
2. **Drug Explorer:** ChEMBL profile, indications and mechanisms (including any gaps).
3. **Literature Intelligence:** PubMed records with PMID/source links.
4. **Research Room:** agent progress and completed run.
5. **Candidate detail:** evidence list showing source identifiers and source links.

Save PNG files in `docs/screenshots/` with these names:

- `disease-explorer.png`
- `drug-explorer.png`
- `literature-intelligence.png`
- `research-room.png`
- `candidate-evidence.png`

Before committing, remove any personal data, API keys, tokens, local paths, or private research inputs visible in the screenshots. Only capture real output; do not fabricate result counts or scientific claims.
